# PEMDAS-calculator
# Simple PEMDAS & Bitwise Calculator

## Overview
A beginner-level Python command-line project that calculates 3-number arithmetic expressions according to manual PEMDAS precedence rules and performs binary bitwise logical operations.

## Repository Structure
- `main.py`: Interactive user program loop.
- `pemdas_engine.py`: Performs step-by-step math according to PEMDAS rules.
- `bitwise_engine.py`: Performs standard binary operations.
- `validator.py`: Handles input error checking.
- `display.py`: Manages menus and binary output formatting.
- `statement.md`: Project scope and objectives.

## How to Run
Run the main script in your terminal:
```bash
python main.py
