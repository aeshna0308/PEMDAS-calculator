# Project Statement

## Problem Statement
Command-line calculators usually evaluate simple standard arithmetic or bitwise expressions separately. This application unifies beginner-friendly arithmetic evaluations using explicit PEMDAS rules alongside bitwise binary operations into a single interface.

## Target Users
Computer science students, academic evaluation teams, and beginner programmers learning binary math and operator precedence.

## Key Features
1. Sequential evaluation of math problems using explicit PEMDAS operator precedence.
2. Binary bitwise operations (AND, OR, XOR, NOT, Left Shift, Right Shift).
3. Input validation for inputs to prevent runtime exceptions.
4. Clean formatted visual menu interfaces and binary results.
